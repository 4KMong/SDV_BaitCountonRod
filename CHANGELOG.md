# Changelog

All notable changes to Bait Count On Rod are documented here.

## 1.0.1 - 2026-09-05

Maintenance release.

- Replaced reflection-based bait lookup with direct `FishingRod.GetBait()` usage.
- Added sprite-cache invalidation when SMAPI invalidates content assets.
- Added GitHub Releases as an update-check channel alongside Nexus Mods.
- Kept the existing bait icon and count placement unchanged.

## 1.0.0

- Initial release.
- Added equipped bait icon and remaining bait count to fishing rod icons in menus.
- Added support for colored/specific bait rendering.
